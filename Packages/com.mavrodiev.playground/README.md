# Playground

Playgrounds for learning Unity, topic by topic. Each playground is a sample with its exercises: import it, open it, poke it.

## Install
In Unity: *Edit → Project Settings → Package Manager → Scoped Registries → +* — Name `Petar Mavrodiev`, URL `https://registry.npmjs.com`, Scope `com.mavrodiev` → **Save**. Then *Window → Package Manager → My Registries → Petar Mavrodiev*.

## Also needed: the OpenUPM registry (for the volumetric fog)
Some samples use the [CQF URP Volumetric Fog](https://openupm.com/packages/com.cqf.urpvolumetricfog/) (MIT), which comes from OpenUPM. Add a second scoped registry in the same place: Name `OpenUPM`, URL `https://package.openupm.com`, Scope `com.cqf.urpvolumetricfog` → **Save**.
